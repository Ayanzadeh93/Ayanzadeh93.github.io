Start a study session

A focus tool built around what actually derails an ADHD study session — one visible task, a timer you set to whatever is survivable today, and somewhere to put the thought that would otherwise become a new tab.

Everything stays in this browser. A profile is a local name for your own data — there is no account, no password and no server. Nothing you type here leaves the device, which also means it does not follow you to another one.

Account sync is not wired up yet. When a Firebase project is configured, this button signs in for real and the same pack follows you across devices. Until then it stays disabled rather than pretending to work.
