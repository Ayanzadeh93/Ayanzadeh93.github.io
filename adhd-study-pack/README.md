# ADHD Study Pack — moved

The app is **not** in this public portfolio repository. The live product is
served from GitHub Pages at
<https://www.ayanzadeh.com/adhd-study-pack/> (also reachable via
`ayanzadeh93.github.io/adhd-study-pack/`).

What is left here is a thin redirect: `index.html`, plus `privacy.html` and
`terms.html`, which keep resolving because the app's Google OAuth verification
references those URLs. None of these files is the application source.

## Why

This directory used to hold a second, full copy of the app. The two copies
drifted — by September 2026 this one was several releases behind, so
`www.ayanzadeh.com/adhd-study-pack/` was serving an old build while the real
app moved on. One copy, one deployment, no drift.

## Private source

The application repository may be **private** (GitHub Pro / Student Developer
Pack). With Pro, Pages still publishes the live site: visitors can use the app;
they cannot browse or clone the source. Do not put a full copy of the app back
into this public portfolio.

## Note for anyone following a bookmark

A workspace saved **without an account** is stored per web address, so a local
workspace saved on an older origin may not follow you automatically. The
redirect page offers to save it as a file first; the app's
**Setup → Account and data → Import a backup** takes it back. Signed-in
accounts are unaffected — that workspace lives in the account.
